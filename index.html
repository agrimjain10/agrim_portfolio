Full-stack web app Apr — May 2026

TradeDesk

A paper-trading platform for exploring the stock market with virtual funds, live and fallback data, and a portfolio that reflects each trade.

  • Simulated buy/sell orders with balance checks and weighted-average pricing.
  • REST APIs for holdings, watchlists, trade history and dashboard data.
  • Stock search, intraday charts, market depth and profit-and-loss tracking.
  • React
  • Node.js
  • Express
  • MySQL
Explore source code ↗
Inside the build +

Architecture. React frontend → Node.js / Express API → MySQL. A separate market service integrates external stock data with fallback behaviour.

A detail that matters. Trade execution checks the available balance and updates weighted-average pricing, holdings and portfolio valuation.
